1. What is Amazon CloudWatch?

Amazon CloudWatch is an AWS monitoring and observability service.

It collects and monitors information about your AWS resources and applications so you can understand their performance, health, and behavior.

Think:

CloudWatch = monitor what's happening in your AWS environment.

For example, you can monitor:

EC2 CPU usage
Lambda invocations
Lambda errors
API Gateway requests
Application performance
Resource utilization
2. What are CloudWatch Metrics?

A metric is a numerical measurement collected over time.

For example, an EC2 instance might produce:

CPUUtilization
     ↓
  25%
  40%
  72%
  91%

These values are a metric.

Other examples:

AWS service	Example metric
EC2	CPUUtilization
Lambda	Invocations
Lambda	Errors
API Gateway	RequestCount
DynamoDB	ConsumedReadCapacityUnits
Easy distinction

CloudWatch = monitoring service

CloudWatch Metric = numerical measurement being monitored

3. Why are metrics collected over time?

A single value isn't very useful.

Suppose:

10:00 → CPU = 20%
10:05 → CPU = 35%
10:10 → CPU = 60%
10:15 → CPU = 90%

Now you can identify a trend.

CloudWatch can display metrics as graphs and allow you to create alarms based on them.

4. CloudWatch Alarm

This is another concept you should remember.

A CloudWatch Alarm watches a metric and performs an action when a defined threshold is reached.

Example:

EC2 CPUUtilization
        ↓
     > 80%?
        ↓
      YES
        ↓
   CloudWatch Alarm
        ↓
   Trigger action

For example:

If EC2 CPU utilization stays above 80%, trigger an alarm.

The alarm can be integrated with services such as Amazon SNS to send notifications.

5. CloudWatch Logs vs Metrics

This is a common exam distinction.

Metrics

Numerical measurements.

Example:

Lambda had 500 invocations.

Logs

Detailed records/events generated by applications and AWS services.

Example:

2026-09-04 10:25:31
ERROR: Database connection failed

So:

Metrics → numbers and measurements

Logs → detailed event information

6. For your AI/ML context

CloudWatch can help monitor AI applications and the AWS infrastructure running them.

For example, if your application uses Lambda:

Lambda
 ├── Invocations
 ├── Errors
 ├── Duration
 └── Throttles
       ↓
   CloudWatch
       ↓
   Monitoring

You can identify whether your application is experiencing errors, high latency, or increased usage.

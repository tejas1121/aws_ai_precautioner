Amazon Textract is a fully managed AWS AI service that automatically extracts text and structured data from documents.

Simple definition

Amazon Textract = Extract information from scanned documents, forms, and tables. 📄 → 📝

Unlike simple OCR, Textract can understand the structure of a document, such as forms and tables.

How Textract works
📄 Document
   ↓
Amazon Textract
   ↓
Text + Structure + Data
   ↓
Application

For example, give Textract a scanned invoice:

┌─────────────────────────────┐
│       ABC STORE             │
│                             │
│ Product     Qty    Price    │
│ Laptop       1    ₹60,000   │
│ Mouse        2     ₹2,000   │
│                             │
│ Total: ₹62,000              │
└─────────────────────────────┘

Textract can extract:

ABC STORE

Product | Qty | Price
Laptop  | 1   | ₹60,000
Mouse   | 2   | ₹2,000

Total: ₹62,000
1. OCR / Text Detection

Textract can extract printed text from documents.

Example:

Scanned document
       ↓
     Textract
       ↓
Extracted text

This is useful when documents aren't available as machine-readable text.

2. Forms ⭐

Textract can extract key-value pairs from forms.

For example:

Name:     Tejas
Email:    tejas@example.com
Phone:    9876543210

Textract can understand the relationship:

Name  → Tejas
Email → tejas@example.com
Phone → 9876543210
Exam clue

"Extract form fields / key-value pairs from documents."

→ Amazon Textract

3. Tables ⭐

Textract can identify and extract information from tables.

Example:

Product       Quantity     Price
--------------------------------
Laptop           1        ₹60,000
Mouse            2         ₹2,000

Instead of treating the entire page as plain text, Textract can preserve the table structure.

Exam clue

"Extract data from tables in invoices."

→ Amazon Textract

4. Analyze Documents

Textract provides APIs for analyzing documents and extracting different types of information.

Depending on the API/use case, it can detect:

Textract vs Comprehend

Another possible exam trap.

Textract

Extracts information from documents.

📄 Invoice
 ↓
Textract
 ↓
"Total = ₹62,000"
Comprehend

Analyzes text that you already have.

📝 "The service was terrible."
 ↓
Comprehend
 ↓
Sentiment = Negative

So:

Textract gets the text/data OUT of the document.
Comprehend analyzes the text.

They can even be used together:

📄 Customer document
       ↓
   Textract
       ↓
Extracted text
       ↓
   Comprehend
       ↓
Sentiment / Entities / Key phrases
Textract vs Traditional OCR

A useful conceptual distinction:

Traditional OCR:

Mainly recognizes characters/text.

Textract:

Extracts text and understands document structures such as forms and tables.

For AIF-C01, if the scenario specifically mentions forms, tables, key-value pairs, invoices, receipts, or structured document extraction, Textract is usually the stronger answer.
